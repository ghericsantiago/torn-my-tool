Settings

days (1–90)

Longer retention = more cycles for better predictions, but more disk space.
Reducing this will immediately prune old data on the next poll.

items (1–999)

Used to calculate Potential income = profit/unit × min(stock, capacity).

min (0–60)

Extra time added before departure for bank withdrawals, slow network, etc. "Leave in X" will tell you to start preparing this many minutes earlier.

% (0–100)

Deducted from sell price before calculating profit. Torn charges 5% by default.
